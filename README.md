## Что собрано

- Тарифы электроэнергии: котловые тарифы, тариф ФСК/ЕНЭС на передачу, сбытовые надбавки и проверка интеграции в расчетные модули.
- ПУНЦ и пиковые часы: зона ГП, регион, плановые ЧПН СО по ценовой зоне выбранного субъекта РФ.
- Ценовые категории 1-6: первый единый расчетный экран по выбранному региону, напряжению, объему и мощности.
- Аптайм на 4 ЦК: график работы, Pчпн, стоимость энергии, покупной мощности, регионального котлового тарифа или ФСК/ЕНЭС.
- ОРЭМ: эффект РУЦ и исключения сбытовой надбавки.
- Тарифы газ: компонентная раскладка цены газа, ГРО, полнота компонентов и индикатор газификации субъекта РФ.
- Распределенная генерация: CAPEX, OPEX, когенерация, NPV, LCOE и окупаемость.

## GitHub / PR discipline

- Рабочая папка остаётся в `projects/krasny-yar-energo-app`, но синхронизируется отдельным GitHub remote.
- Изменения вести через feature-ветку и draft PR; прямой push в `main` не использовать для рабочих правок.
- Перед push запускать:

```bash
scripts/preflight.sh
```

- GitHub Actions запускает тот же preflight для `main`, `codex/**` и pull request.

## Граница Draft 1

- Это первая связанная оболочка, а не финальная production-миграция всех расчетных ядер.
- Данные котловых тарифов и сбытовых надбавок подключаются из существующего `tariffs-2026`; тариф ФСК/ЕНЭС добавлен как отдельный справочник по приказу ФАС № 1052/25.
- Газовая база подключается из `tariffs-2026` по выбранному субъекту РФ и группе потребления; неполные компонентные строки не применяются как автоматическая цена генерации.
- РУЦ подключается из текущего JSON модуля `orem-node-price-app`.
- Расчеты ЦК/ОРЭМ/генерации работают как браузерный draft; для production нужно поэтапно подключить проверенные Python-ядра и повторить профильное энергетическое QA.
- Для 4/6 ЦК учитывается различие ставки содержания сети по классу напряжения; Pmax не используется как стоимостная база мощности.
